# CustomExitScreen

A Vite + React 18 plugin template for the metatell exit screen.

## Requirements

- Node 20+

## Development

```bash
npm install
npm run dev
```

Vite dev server runs at `http://localhost:5173`.

## Build

```bash
npm run build
```

The Module Federation manifest is emitted to `dist/mf-manifest.json`.

## Exposed module

- `./CustomExitScreen` from `src/components/CustomExitScreen`

## Props

```ts
export type CustomExitScreenProps = {
  reason:
    | "exited"
    | "closed"
    | "denied"
    | "kicked"
    | "left"
    | "connectError"
    | "sceneError";
  isSignedIn: boolean;
  copyByReason: Record<
    CustomExitScreenProps["reason"],
    {
      title: string;
      message: string;
      buttonLabel: string;
      buttonUrl?: string;
      action: "reload" | "home" | "navigate";
    }
  >;
  onPrimaryAction: () => void;
};
```

## Notes

- `.uuid.env` contains `VERSION_ID` and `VITE_VERSION_ID` generated by `npm run set-uuid`.
- Host loads `CustomExitScreen` via Module Federation runtime.
