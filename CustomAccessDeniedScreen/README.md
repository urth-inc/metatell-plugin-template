# CustomAccessDeniedScreen

A Vite + React 18 plugin template for the metatell access denied screen.

## Requirements

- Node 20+

## Development

```bash
npm install
npm run dev
```

Vite dev server runs at `http://localhost:5173`.

## Build

```bash
npm run build
```

The Module Federation manifest is emitted to `dist/mf-manifest.json`.

## Exposed module

- `./CustomAccessDeniedScreen` from `src/components/CustomAccessDeniedScreen`

## Props

```ts
export type CustomAccessDeniedScreenProps = {
  isSignedIn: boolean;
  accessDeniedMessageForLoggedInUsers: string;
  accessDeniedButtonTextForLoggedInUsers: string;
  accessDeniedButtonUrlForLoggedInUsers: string;
  accessDeniedMessageForAnonymousUsers: string;
  accessDeniedButtonTextForAnonymousUsers: string;
  accessDeniedButtonUrlForAnonymousUsers: string;
  onButtonClick: () => void;
};
```

## Notes

- `.uuid.env` contains `VERSION_ID` and `VITE_VERSION_ID` generated by `npm run set-uuid`.
- Host loads `CustomAccessDeniedScreen` via Module Federation runtime.
